Trade-offs

A — Combobox

  • Minimal code change
  • Familiar UX pattern
  • Works inside existing form rows
  • Still one product at a time
  • No category browsing
  • No product details visible

B — Picker Sheet

  • Category filters + full search
  • Can select multiple at once
  • Scales to thousands of items
  • Familiar drawer pattern (like mobile apps)
  • Extra click to open sheet
  • More code to build

C — Inline Instant-Add

  • Fast — no extra clicks, just search & add
  • Barcode scanner friendly
  • Qty visible alongside items
  • Bigger layout change to form
  • Less browsable (need to know name)
  • Shifts form UX away from rows
